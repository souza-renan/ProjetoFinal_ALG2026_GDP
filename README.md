# ProjetoFinal_ALG2026_GDP
## Locadora de FIlmes

### As locadoras surgiram na década de 1970 e entraram em declínio por volta de 2010. Este projeto propõe desenvolver um sistema próprio de locadora utilizando Portugol, com foco em lógica de programação. É uma aplicação básica, executada diretamente no terminal.
